日本球场地区多语言标准化工具

Windows 新手使用说明｜离线依赖版

这个工具会做什么？

自动清洗
过滤城市或地址为空的服务行。
解析日本地址
提取都道府县和现行市町村，排除郡名。
生成多语言 Excel
输出球场明细、市町村汇总和 47 都道府县对照。
保留异常记录
看不懂的地址写入 CSV，不会让整个程序中断。
原始 .xlsx→双击/拖拽处理→标准工作簿 + 异常 CSV

第一次使用：只需完成一次

1
安装 Python
如果电脑还没有 Python，请从 Python 官网安装 Python 3.9 或更高版本。安装界面务必勾选 Add Python to PATH。安装后重新打开本目录。
2
双击“首次安装依赖.bat”
它会在本目录创建 .venv，并从 wheels 文件夹离线安装依赖。看到“安装完成”即可。
依赖无需联网下载。 Excel 处理库及其依赖安装包已经放在本目录的 wheels 文件夹中。只有电脑本身没有 Python 时，才需要先安装 Python。

日常使用：推荐拖拽

1
关闭正在编辑的原始 Excel，确认文件后缀是 .xlsx。
2
用鼠标把原始 Excel 文件拖到 “开始处理Excel.bat” 图标上，然后松开。
3
等待黑色窗口显示“处理完成”。输出文件会保存在原始 Excel 的同一目录。

也可以把唯一一份原始 Excel 放进工具目录后，直接双击“开始处理Excel.bat”。如果目录里有多份原始表，请使用拖拽方式，避免选错。

不会修改原表，也不会覆盖以前的默认输出。 工具生成“原文件名_日本地区多语言对照汇总.xlsx”；如果同名结果已经存在，会自动改成 _2、_3。

原始 Excel 必须满足什么格式？

程序会自动寻找包含以下 5 个表头的 Sheet；表头顺序可以不同，也允许存在额外字段。

必须存在的表头说明
球场id中文球场唯一 ID，可为数字或文本。
国家原始国家字段；输出会统一为“日本”。
球场名称中文球场中文名称。
城市通常填写都道府县中文名。
地址建议保留完整日本地址，支持邮编、日文、中文及常见英文地址。

旧版 .xls 不受支持。请先在 Excel 中选择“另存为”，保存成 .xlsx。

输出文件说明

1. 标准工作簿

包含且只包含 3 个 Sheet：球场明细表（已修正版）、多语言市町村汇总表、都道府县多语言对照表。

2. 异常记录 CSV

文件名以 _异常记录.csv 结尾。即使没有异常，也会保留表头。常见记录包括：

  • 城市或地址为空，已过滤；
  • 地址中无法识别都道府县；
  • 已识别都道府县，但市町村名称存在错字、旧称或特殊写法。

遇到异常时，请先修正原表中的地址，再重新运行。不要直接把异常行随意归入相似地名。

常见问题

双击后提示“没有找到 Python”

安装 Python 3.9+，并勾选 Add Python to PATH。安装完成后重新双击“首次安装依赖.bat”。

提示“有多个原始 Excel”

把要处理的那份 Excel 直接拖到“开始处理Excel.bat”上。

提示缺少字段

检查首行表头是否与本说明中的 5 个字段完全一致，尤其不要多空格或改字。

提示 Permission denied / 文件被占用

关闭 Excel、WPS 或其他正在打开输出文件的程序，然后重试。

安全软件拦截 .bat

批处理文件只会调用本目录 Python 环境，不会上传数据。也可在命令提示符中运行：
.venv\Scripts\python.exe build_workbook.py "D:\你的文件.xlsx"
